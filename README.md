# Escape from Planet G

**Escape from Planet G** is a planned browser-based 3D arcade flight game. Pilot Captain Flynn through Planet G’s surface and cavern systems, rescue Princess Odette near its core, and fly back out while evading the Tallows and their traps.

> **Status:** Pre-development. No playable build or deployment is available yet.

## Planned game

The campaign contains five levels, moving from surface storms to caves, crystal chambers, volcanic passages, and Odette’s prison near the core. Players will be able to switch between a cockpit view and a camera behind the ship. Hull damage, checkpoints, an extraction objective, and an escape sequence form the main gameplay loop.
